# Novium v0.1 Roadmap

## What runs now

`novium --run file.nvm` executes a deliberately small core: integers, floats, booleans, strings, `let`/`let mut`/`var`, arithmetic and comparisons, function calls, `return`, `if`/`elif`/`else`, `while`, compound assignment, and `print`.

This interpreter is a development milestone, not the final performance model. It gives the language executable semantics before a native backend is introduced.

## Path toward replacing C++ in personal software

1. Finish the core: loops, arrays, structs, modules, diagnostics, and a stable standard library.
2. Emit portable C as the first native backend. This keeps generated output inspectable and lets Novium call mature C APIs immediately.
3. Add a C ABI layer: `extern "C"` imports and exports, shared-library builds, and a documented type mapping.
4. Add resource safety: `defer`, RAII-style resource wrappers, and explicit `unsafe` blocks before attempting borrow checking.
5. Add an LLVM backend only after the language semantics and C ABI are stable.

## Non-goals for v0.1

Rust-equivalent lifetime analysis, a garbage-collected scripting runtime, web compilation, CUDA, and package publishing are separate projects. They should not block a reliable native core.
